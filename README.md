# CRUD de Contatos em Python

Projeto simples de gerenciamento de contatos desenvolvido em Python utilizando SQLite como banco de dados.

O sistema funciona via terminal e permite criar, visualizar, atualizar e remover contatos.

## Funcionalidades

- Criar contatos
- Listar contatos
- Atualizar contatos
- Deletar contatos

## Tecnologias utilizadas

- Python
- SQLite3

## Estrutura do projeto

crud-contatos-python
│
├── contatos.db
├── crud_contatos.py
└── README.md

## Como executar

1. Clone o repositório

git clone https://github.com/rafael-adspy/crud-contatos-python

2. Entre na pasta do projeto

cd crud-contatos-python

3. Execute o programa

python crud_contatos.py
